## 2. 题目形式：3 个释义 + 「以上都不对」+「不认识」

每题固定 5 个选项：

```text
[ 中文释义 A ]
[ 中文释义 B ]
[ 中文释义 C ]
[ 以上都不对 ]
[ 不认识   ]
```

关键设计：

1. **正确答案不一定是 A/B/C。** 服务端以约 **75%** 的概率把该词的正确释义放进
   A/B/C；剩下 **25%** 的题三个释义全是干扰项，正确答案是「以上都不对」。
2. 正确选项在 `0..3` 上近似均匀分布。对 184 道真实题目的统计：

   | 正确下标 | 0 | 1 | 2 | 3（以上都不对） |
   | --- | --- | --- | --- | --- |
   | 次数 | 41 | 48 | 47 | 48 |

   这正是「75% 放入正确释义并随机打乱 + 25% 全错」的结果：每个下标约 25%。
3. **「不认识」是独立信号**（`selected_index = 4`），不是普通错答。服务端会把它
   记为 `unknown`，扣分力度与「答错」不同（见 §4）。
4. 干扰项多为**同档位、同词性**的其它词释义，偶尔会出现语义相近的干扰项
   （如 `acceptable` 的干扰项 `adj. 适当的`）。

复现代码里的 `make_question()` 完整实现了这套生成逻辑。

## 3. 自适应难度：档位 ≈ 词汇量 / 1000

每道题带一个 `level`（0 起）。从 200+ 道题的观察看：

- `level` 是**词频档位**，每档约 1000 词；档位越高，词越生僻。
- 档位对应的难度阈值约为：

  ```text
  T(level) = 1000 * level + 100
  ```

  例如 level 8 的词大约在「词汇量 8100」附近成为 50% 认识的分界线。
- 第一题固定在 **level 3 或 4**（热身）。
- 之后正常情况下，下一题档位 ≈ `round(score / 1000)`，偶尔向下偏一档。
- **探顶机制**：连续答对 **4 题**后，会跳到当前档位上方 3\~4 档（`level + 3/4`），
  并在后续答对时继续上抬（每次 +1\~2 档），最多探 6 题；一旦答错或点「不认识」，
  立即结束探顶、回到 `score/1000` 附近。线上偶尔会在探顶失败后 6 题内再探一次；
  复现代码最多探 2 次。

真实轨迹中的例子（`score` 是答完当前题后的分数）：

| 已答 | score | 下一题 level | 说明 |
| --- | --- | --- | --- |
| 1 | 1166 | 1 | 正常 |
| 4 | 3187 | 6 | 连续 4 对，开始探顶 |
| 5 | 4180 | 8 | 探顶中，答对继续上抬 |
| 6 | 4012 | 3 | 探顶遇到「不认识」，回到前沿 |
| 20 | 6920 | 6 | 正常 |
| 21 | 7101 | 7 | 正常 |

这套「热身 → 探顶 → 前沿采样」的策略，比固定分层抽样更快找到词汇天花板。

## 4. 分数更新：Elo / IRT 式估计

这是整个算法最核心的部分。把 `score` 记作 `V`，题目档位记作 `L`，已答题数记作
`n`，则：

```python
p = sigmoid((V - (1000 * L + 100)) / 2500)   # 预期答对概率
K = 2000 / (1 + n / 14) ** 1.5               # 本题步长（随题量衰减）

correct : V += K * (1 - p)
wrong   : V -= K * p
unknown : V -= 0.625 * K * p
```

含义：

- `p` 是 IRT 的**项目特征曲线**：词汇量越高、题目越简单，预期答对概率越高。
- `K` 是**学习率/步长**：初始约 2000 分，随题量按 `n^-1.5` 衰减；答得越多，
  单题影响越小，分数越稳。
- **答对**：按「意外程度」加分——在远高于当前估计的档位上答对，`p` 很小，
  `1-p ≈ 1`，一次能加接近 `K` 分；在简单档位答对，`p` 接近 1，几乎不加分。
- **答错**：按「意外程度」扣分——在简单档位答错（`p` 大）扣得多；在远高于
  当前估计的档位答错（`p` 小）扣得少。
- **不认识**：方向同答错，但权重是 `0.625`，即「不认识」比「选错」略轻。

### 4.1 参数是怎么来的

用 5 组真实接口轨迹（共 150+ 题，覆盖高正确率、低正确率、大量「不认识」三种
策略）做最小二乘拟合，得到：

| 参数 | 拟合值 | 取整后 |
| --- | --- | --- |
| `SCALE` | 2468.75 | **2500** |
| `LEVEL_WIDTH` | 1026.56 | **1000** |
| `LEVEL_OFFSET` | 109.375 | **100** |
| `K0` | 1968.75 | **2000** |
| `TAU` | 13.9375 | **14** |
| `GAIN_EXP` | 1.5 | **1.5** |
| `UNKNOWN_FACTOR` | 0.625 | **0.625** |

拟合值全部落在整数附近，这强烈说明服务端用的就是右侧这组常数。

## 5. 置信区间：`score_interval` 与 `delta`

响应里的：

```jsonc
"score_interval": [583, 1166],
"delta": [-0.5, 0.0]
```

满足：

```text
lower = score * (1 - delta_abs)
delta = [ -delta_abs, 0.0 ]
```

即区间是**单边的** `[下界, 当前估计]`，`delta_abs` 是相对宽度。

观察到的 `delta_abs` 有一条非常规律的「有效样本量」规律：

```python
# 初始 n_eff = 0
if correct:
    n_eff = 1 if n_eff == 0 else n_eff + 0.5
else:                      # wrong / unknown
    n_eff = max(1, n_eff * 0.5)

delta_abs = clamp(0.8 / (2 * n_eff), 0.01, 1.0)
```

- 第一题答对：`n_eff = 1`，`delta_abs = 0.4`（线上约 0.5）；第二题答对：
  `n_eff = 1.5`，`delta_abs ≈ 0.27`（线上 0.25）。整体 RMSE 约 0.035。
- 答错一次：`n_eff` 减半，区间立刻变宽。
- 连续答对：`n_eff` 每两题 +1，区间缓慢收窄。
- 下限 `0.01`：线上最少也会保留 1% 的相对区间。

用这套规则回放高正确率轨迹，`delta_abs` 的 RMSE 约 **0.035**；回放大量错答
轨迹约 **0.071**。

> 注意：这是对区间**行为**的拟合，不是服务端后验分布的严格推导。服务端可能
> 用的是 Beta 后验或粒子滤波，但对外表现与上式高度一致。

## 6. 结果页与覆盖率

- 前端规定**最少答满 20 题**才能看结果；可以继续答，分数持续收敛。
- 结果页显示的「词汇量」就是测试过程中的 `score`，不是结果接口重算的。
- `vocabresult` 额外返回：
  - `position`：超过百分之多少的用户；
  - `coverage`：10 个词表的认识率；
  - `error_words`：答错的词及释义；
  - `last_test`：本次测试的完整状态。

线上的 10 个覆盖率分类：

```text
小学英语 / 英语四级 / 英语六级 / 研究生英语 / 雅思词汇
托福词汇 / GRE词汇 / 哈利波特词汇 / 美剧常用词汇 / 经济学人词汇
```

前 7 个与 ECDICT 的 `zk / cet4 / cet6 / ky / ielts / toefl / gre` 标签基本对应；
后 3 个是欧路自建词表。覆盖率是**模型估计值**：对词表中每个词，用最终 `score`
和该词的档位算 `sigmoid((V - T(L)) / 2500)`，再取平均，而不是「已答题正确率」。

复现代码用 ECDICT 标签实现了前 7 个分类，后 3 个因缺少词表未复现。

## 8. 与仓库现有实现的对比

仓库已有 [`apps/api/app/services/vocab.py`](../apps/api/app/services/vocab.py)，
它用的是**固定分层抽样**：

- 25,000 词按 rank 切成 10 段，每段固定抽 5 题，共 50 题；
- 每段算「认识率」，做单调非增平滑（PAV）后 `Σ 段宽 × 认识率`；
- 认识率要显著高于蒙对才计入，并扣掉蒙对部分（2026-11 改，见 §8.3）；
- 题面与欧路/CAT 对齐：3 个释义 +「以上都不对」，正确释义只出现 75%，「以上都不对」固定为最后一项（2026-11 改）；
- 反盲猜（2026-11b 改）：干扰项优先同词性（封掉按词性排除）；释义按义项清洗掉
  `=别名`、`xxx的过去式`、人名地名、英文原词，保留同一词的其他义项，
  详见 [vocab-assessment.md](vocab-assessment.md) §2.2。

欧路用的是**自适应 Elo/IRT**：

| 维度 | 现有实现 | 欧路 |
| --- | --- | --- |
| 选题 | 固定每段 5 题，从易到难 | 按当前估计动态选档，连续答对会探顶 |
| 估分 | 段认识率 × 段宽 | 单点 Elo 更新，`V += K(o-p)` |
| 题量 | 固定 50 题 | 最少 20 题，可无限继续 |
| 单题影响 | 有界（≤ 段宽/该段已答数） | 随 `n^-1.5` 衰减，早期影响大 |
| 蒙对处理 | Wilson 下界显著高于 12% 才计入，并按 `c=0.12` 折算（§8.3） | IRT 的 `p` 天然处理，答错/不认识分别扣分 |
| 覆盖率 | 无 | 10 个词表的模型估计 |

现在欧路式自适应算法已作为独立服务 `vocab_adaptive.py` 接入（对外 `algo` 名为
`adaptive`，不绑定欧路；旧值 `eudic` 仍作为别名兼容），路由按 `algo` 开关分发，
前端协议保持不变；`score_interval` / `level` 已下发，`coverage` 暂未在结果页展示。

### 8.1 本地实现的稳定性调整（2026-11）

真实使用中发现两个问题：首次 12226、后程 36/50 却只有 8130。逐题日志显示，
后者在第一次探顶失败后，直到第 12 题才再次探顶且立即失败；之后第 25–32 题
连对 8 题，但旧规则「第二次探顶必须在首次失败后 6 题内」已经过期，分数被
压在低档位。因此本地实现做了以下调整（与欧路原版行为不同）：

| 项目 | 原实现 | 现在 |
| --- | --- | --- |
| 首题档位 | level 3–4 | level 1–2（高频词热身，避免一上来就是生僻词） |
| 探顶次数 | 最多 2 次，第二次限 6 题内 | 最多 3 次；两次之间至少间隔 8 题，后程连对仍可探顶 |
| 题量上限 | 50 题 | 80 题（50 题后提示可结束，也可继续提高稳定性） |
| 得分估计 | Elo 增量更新，步长随题数衰减，结果受作答顺序影响 | 网格贝叶斯 EAP：取后验均值，给定题目与结果时**与作答顺序无关** |
| 猜测校正 | 未建模，蒙对按「认识」计 | 3PL 似然：答对 `c + (1-c)p`，答错 `(1-c)(1-p)`；`c = 0.12` |
| 置信区间 | `n_eff` 每错一次减半，区间单边且经常固定 ±40% | 后验标准误 + 换题方差下限 `FORM_SD = 1200` 的 95% 区间 |

EAP 的实现（501 个网格点：0, 50, …, 25000）：

```python
# 每题把似然乘进后验（对 log 后验做加法）
log_post[i] += log(c + (1 - c) * p)          # 答对
log_post[i] += log((1 - c) * (1 - p))        # 答错
log_post[i] += 0.625 * log(1 - p)            # 「不认识」，延续原版的软惩罚
# 归一化后
score = Σ θ_i * post_i                        # 后验均值
half = 1.96 * sqrt(se^2 + FORM_SD^2)
score_interval = [score - half, score + half]
```

`c` 不是 4 选 1 的 0.25，而是「不会时仍选择猜」的比例（观测约 45%–50%）
乘 0.25；直接用 0.25 会把诚实点「不认识」的用户也当成蒙对。`FORM_SD`
弥补模型只考虑答题噪声、忽略「换一套题」难度抽样方差的缺陷：实测六次
80 题的总标准差约 1,400 分，其中后验标准误约 700–900 分。

后验是各题似然的乘积，交换答题顺序不会改变最终后验，因此得分不再受
「先对后错」还是「先错后对」影响。先验取 `N(1000, 3000)` 截断到
`[0, 25000]`：均值低让前几题从高频词缓慢爬升，方差大保证数据能主导估计。
模拟中真实能力 10,000 的用户 80 题后 RMSE 约 550 分；20,000 的用户
不再像 Elo 那样被系统性低估（Elo 约 17,300，EAP 约 19,400）。

### 8.2 词频题库 CAT（2026-11，2026-11e 二维化 + 锚题）

第三套算法 `cat` 保留同一题型，替换选题与估计：

| 项目 | adaptive | cat |
| --- | --- | --- |
| 难度 | 1000 词一档，档内同难度 | 精确词频 rank |
| 模型 | 一维 EAP（θ） | 二维 EAP（θ, α），同 adaptive2 |
| 词汇量 | θ（50% 阈值） | 曲线面积 Σ 1000 × P(know) |
| 选题 | 档位 ±1 + 连对探顶 | 当前能力附近按 3PL Fisher 信息量选题；第 5、10、15… 题插入跨档锚题（2 / 6 / 10 / 14 / 18 / 22 档轮换） |
| 曝光 | 档内随机 | 信息量最高的 12 题中加权随机，避免重复 |
| 参数来源 | 固定档位映射 | 词频先验；可被 `data/calibration/vocab_cat_items.json` 覆盖 |

为什么需要锚题：没有锚题时 CAT 只在 θ ±80 rank 内采样，而「陡曲线 + 高 θ」
与「平曲线 + 中等 θ」在窄带内的答对率几乎相同，α 与 θ 无法分别识别。锚题
提供跨档正确率，α 才能被数据约束（模拟 α≈0.28 的平缓曲线时，α 估计从
0.90 拉回 0.75）。

标定文件格式：

```json
{"version": 1, "items": {"abandon": {"b": 5230, "a": 0.00052}}}
```

`b` 是分数尺度上的难度（0–25000），`a` 是分数尺度上的区分度
（1PL 默认 `1/2500`；2PL 标定后按 `a_logit / 2500` 换算）。文件不存在时
所有词都用 `b = rank`、`a = 1/2500`。

**标定数据现状**：日志里的经典算法 session 绝大多数是脚本模拟（同一天
1,925 个 session、准确率都是 5 的倍数、时间戳成组重复），只能恢复档位
阈值，无法做逐词标定。因此 CAT 目前先用词频先验；等真实作答积累后，
再拟合 1PL/2PL 并写入上面的覆盖文件。

### 8.3 经典算法的猜测校正（2026-11）

一次真实的 50 题：15k 以下 33/35 正确，15k 以上 4/15（27%，与四选一纯猜
区分不开），旧实现给出 16,500，比同一批答案在 EAP 下的 12,973 高 3,500：

1. **按段点估计判断**：b7、b8 各 2/5 = 40%，超过 25% 的猜测下限，各记
   `3000 × 0.4 = 1200`；但 5 个样本下 2/5 与蒙对分不开
   （`P(≥2/5 | p=0.25) = 0.37`）。
2. **不扣除蒙对**：即使整段真的认识 40%，其中也有一部分来自蒙对。

现在每段先过一道 Wilson 检验，再做猜测校正：

```python
if _wilson_lower(known, n) <= GUESS_RATE:   # c = 0.12，与 vocab_adaptive 一致
    continue                                # 没有显著高于蒙对的知识信号
know_rate = (smoothed_rate - GUESS_RATE) / (1 - GUESS_RATE)
```

同一批答案现在得 13,977（结果页 13,980），与 EAP 的 12,973 只差约 1,000。
两者的口径仍然不同：经典算法是「认识多少词」的面积估计，EAP 是「正确率
56% 对应的词频位置」，不能当成同一个数字互相比较。

### 8.4 历史成绩只定起点（2026-11b，2026-11c 修正塌陷，2026-11d 封顶 CAT 起点，2026-11e 二维 CAT）

issue #42 最初把最近一次同算法 `score` 当作新测试的 θ 先验均值。实测发现
短测试会把这个先验原样记成一次成绩（答 1 题的 adaptive 会话记下 13,028，
纯先验 EAP 只有 1,950），下一次又以 13,028 为先验，形成链式抬分：正确率
不变，分数却次次上涨。

现在改为：

- 历史成绩只换算成**起点**：首题档位从这一档开始，并用均值 = 档位起点
  （`level × 1,000 + 100`）、标准差 `sd = max(4,000, 历史 sd)` 的**宽先验**
  初始化后验；
- 为什么不能只用默认 `N(1000, 3000)`：首题答完后后验会被默认先验拉回均值
  （截断后约 2,800），第二题从历史档位直接跌到 2–3 档——上线后实测的会话
  均为「Q1 14 档 → Q2 3 档」，等于历史起点只生效一题；
- sd 也不能太紧：旧版同日历史 sd ≈1,500，短测试几乎照抄旧分。4,000 足够宽，
  答几题后数据即可主导；
- **CAT 的起点额外封顶在 8 档**（2026-11d）。CAT 只在 θ ±80 rank 内选题，
  起点 14/16/17 会让整场锁在高频段；对曲线很平的用户（本例 α≈0.28），
  固定斜率会把高分档位的一串答对解释成 θ 继续上移。用同一历史曲线模拟：
  起点 8 / 14 / 16 / 17 档分别得 13,800 / 16,600 / 17,500 / 18,100，而三场
  真实 CAT 正好是 12,339 / 16,194 / 16,928。封顶后三场都会回到约 13,800，
  与 classic / adaptive 的 13,900 / 14,100 对齐；6k / 18k / 24k 真值用户
  均未变差（6k 段正偏从 +21% 降到 +11%，18k / 24k 在 ±3% 内），起点热身的
  收益也保留。2026-11e 的二维模型 + 锚题把同一曲线（起点封顶 8 档）的 θ
  估计提到约 14,900、面积约 15,100（真值 θ≈16,300、面积≈15,000），但起点
  仍是主要偏差来源，锚题不能替代封顶；
- **少于 20 题的测试不写入历史**，避免「看几题就退出」污染趋势和起点；
- `VOCAB_HISTORY_PRIOR=false` 仍可关闭历史，关闭后首题从 1–2 档开始。

这样既保留了熟手不用从第 1 档热身的体验，又切断了测试之间的分数反馈环。

### 8.5 低频纯音译清理（2026-11b）

低频段有一批纯音译词：人名/地名（`amarna → 阿玛那`、`diem → (德)迪姆`）、
乐器/音乐（`bandoneon → 班多钮`、`toccata → 托卡塔`）、药名（`codeine → 可待因`、
`morphine → 吗啡`）、单位/币种（`ohm → 欧姆`、`joule → 焦耳`）等。这些词的
中文释义与英文发音高度对应，四选一时可以按音直接猜中，属于送分题。

处理分两层：

1. **兜底不再保留专名**：`gloss()` 在剥掉 `[医][计]` 等领域标签时，过去会把
   `[人名]/[地名]` 一起剥掉，留下裸名字（`(德)迪姆`）。现在先检查原始标签，
   整词只有专名时直接剔除；同一行里还有普通义项时只保留普通义项。
2. **低频纯音译黑名单**：`data/wordlists/transliteration_blacklist.json` 收录
   120 个纯音译词，抽题时过滤。高频常用外来词（`coffee/sofa/logic`）是真实
   词汇，保留不动。

维护脚本 `apps/api/scripts/scan_transliterations.py` 用拼音声母与英文音标做
离线音近扫描，列出候选供人工复核（有误报，如 `insomnia → 失眠`；需要临时
`uv run --with pypinyin`，不是运行时依赖）。

代价：每段只有 5 题，段边界附近会因抽样波动在「计入 / 清零」之间跳动，
经典算法的单次波动约 ±1,500–2,000 词（结果页不显示区间）。

阈值模型模拟（真实 V=8000、不会的词一半乱猜，200 次）：

| 估计量 | 均值 | 标准差 |
| --- | --- | --- |
| 旧（点估计 ≤25% 清零） | 8,261 | 677 |
| 新（Wilson + 猜测校正） | 8,030 | 144 |

真实 V=20000 时分别是 20,379 / 19,964（旧的上偏随 V 增大而增大）。

**题面也已对齐（2026-11）**：经典算法原来 4 个选项里永远包含正确释义，可以用
排除法或词形猜出来（实测 rank 21k–25k 的段答对 4/5，其中 capeskin、aglitter
这类词词形透明；而同一天的自适应测试在 9k–11k 只有约 60% 正确）。现在改成与
欧路/CAT 相同：3 个释义 +「以上都不对」（固定为最后一个选项），正确释义只出现 75%。
这次改动之后，各算法测的才是同一种能力；此前的历史分数（包括 `vocab_tests`
里的旧记录）不重算，跨算法的趋势对比仍不可靠。

## 9. 局限与合规

- **常数是拟合值**：服务端真实常数不可见；本文给出的是与真实轨迹误差 ~1% 的
  一组整数，足以复现行为，但不保证逐位一致。
- **探顶策略是行为拟合**：连续 4 对开始探顶、每次上抬 1~2 档、最多 6 题，这些
  是从多条轨迹归纳出的规则，线上可能还有随机抖动。
- **词表不同**：复现用仓库的 25,000 词 ECDICT 词表，线上词表更大（排行榜最高
  分约 29,116），档位数可能到 29；复现代码把分数上限设为 25,000。
- **覆盖率后 3 类未复现**：哈利波特 / 美剧 / 经济学人词表不在仓库中。
- **合规**：以上分析仅用于互操作/学习目的。接口只应使用自己的账号、低频调用；
  不要批量刷接口或绕过任何访问控制。

## 10. 一句话总结

欧路词汇量测试 = **「3 释义 + 以上都不对 + 不认识」的 4+1 选项题** +
**按 `score/1000` 选档、连续答对 4 题后探顶的自适应选题** +
**参数为 `(2500, 1000, 100, 2000, 14, 1.5, 0.625)` 的 Elo/IRT 分数更新**。
它用 20~50 题就能把词汇量估计收敛到 ±5% 左右，核心代码不到 100 行。
