# 词汇量评测算法

> 实现：[`apps/api/app/services/vocab.py`](../apps/api/app/services/vocab.py)
> 测试：[`apps/api/tests/test_vocab.py`](../apps/api/tests/test_vocab.py)
> 诊断：[`apps/api/scripts/diagnose_vocab_bands.py`](../apps/api/scripts/diagnose_vocab_bands.py)

## 一句话

把 25000 个词族按词频切成 10 段，每段轮流抽词测试，用「每段认识率 × 段宽」线性累加出词汇量。这是百词斩、欧路等主流词汇量测试的「识别率 × 词频权重」做法。

## 口径

报告的「词汇量」是**识别率加权面积**，不是「认识 50% 词的拐点」：

```
词汇量 = Σ (第 i 段词频宽度 × 该段认识率)
```

- 对于平滑递减的知识曲线，面积 ≈ 1.11 × 50% 拐点（可预期的、恒定的比例差）。
- 对于「尖峰型」知识（认识一批生僻词、漏掉部分常见词），面积口径反而更稳——尖峰尾巴和中间洼地大致抵消。
- 与百词斩/欧路同口径，可直接横向对比。

## 词表与分段

词表：Paul Nation BNC/COCA 25000 词族（rank 1–25000），取其中可作题目的 23611 词。

```
BANDS = (0, 2000, 4000, 6000, 8000, 10000, 12000, 15000, 18000, 21000, 25000)
```

10 段，宽度依次为 2000×6 + 3000×3 + 4000×1，合计 25000。半开区间 `[BANDS[i], BANDS[i+1])`，末段含右端点 25000。

## 抽样（轮询）

下一题始终取自**已答数最少**的段，等价于逐段轮询，保证各段均衡覆盖。每段抽 `ROUNDS = 5` 词，共 `MAX_QUESTIONS = 50` 题。

干扰项从目标词相邻频段（`[rank/2, rank×1.5]`）中随机抽取，保证四选一难度合理。

## 估值与显示平滑

- **估值**：每次作答后，对**全部历史作答**重算 `Σ 段宽 × 认识率`。线性累加，每个词的贡献有界（≤ 段宽 / 该段已答数），天生平滑。
- **显示**：为杜绝「前 10 题爬到 10000+、错一个立刻崩」的突变，显示分朝估值逼近，但**单次变动上限 `SCORE_MAX_STEP = 800`**。
- 前 `MIN_SAMPLES = 3` 题不显示分数（返回 `null`），前端显示「测评中」。

## 参数一览

| 参数 | 值 | 含义 |
| --- | --- | --- |
| `BANDS` | 10 段（见上） | 词频分段边界 |
| `MAX_VOCAB` | 25000 | 词族上限 |
| `ROUNDS` / `MAX_QUESTIONS` | 5 / 50 | 每段抽词轮数 / 总题量 |
| `MIN_SAMPLES` | 3 | 少于该题数不显示分 |
| `SCORE_MAX_STEP` | 800 | 显示分单次最大变动 |

## 为什么不用自适应 MLE

最初实现是「自适应阶梯 + logistic 拟合」（在认识/不认识交界处密集采样，拟合 50% 拐点）。它在**平滑知识曲线**上精度高，但在真实孩子的**尖峰型知识**上有两个致命问题：

1. **同一轮内突变**：阶梯采样到的单个「生僻词碰巧认识」会大幅拉动拐点拟合，分数跳变数千。
2. **两次测评分叉**：阶梯要么「逃逸」到生僻词平台（高估），要么停在平滑拐点（低估），同一人两次结果可差一倍（实测 18.4k vs 9.8k）。

分层抽样 + 比例累加是线性估计量，**没有拐点拟合的分叉点**，因此：

| 指标 | 旧（阶梯 + MLE） | 新（分层 + 比例） |
| --- | --- | --- |
| 两轮间分叉（尖峰模型） | 2 倍 | **±10%** |
| 同一轮内单步最大变动 | 数千 | **≤ 800** |
| 校准（平滑模型） | 高估/低估都可能 | 0–15% 恒定上偏（面积口径） |

> 已试过 isotonic 单调回归（强制认识率随词频递减）作为增强，结果与朴素比例几乎相同（±10% vs ±10%），未采用——不值得增加复杂度。

## 实测结果

三次实跑（成年用户，非目标学生）：

| 次数 | 题量 | 最终分 |
| --- | --- | --- |
| 1 | 20（提前结束） | 14800 |
| 2 | 50 | 14800 |
| 3 | 50 | 15800 |

两次完整测评只差 7%（14800 vs 15800），且该用户答题很诚实（50 题里「猜错」仅 0–1 次，不会的都点「不认识」），无四选一猜测虚高。同时观察到清晰的「尖峰」现象：12000–15000 段认识率 40%（洼地），15000–18000 段反而 60%（生僻词反弹）——分层口径对这类知识天然稳健。

## API 端点

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/vocab/test/start` | 新建会话，返回 `session_id` + 第一题 |
| POST | `/vocab/test/answer` | 作答 `{session_id, choice, unknown}`，返回反馈 + 实时分 + 下一题；答满 50 题返回 `finished` + `result` |
| POST | `/vocab/test/finish` | 提前结束，返回最终成绩（幂等） |

```bash
# 单元 + 回归测试（23 例：分段/估值/流程/稳定性/突变上限）

# 稳定性 + 校准模拟（尖峰 & 平滑两种模型）

# 快速自检（四种极端作答）
uv run --directory apps/api python scripts/smoke_vocab.py
```

**回归测试锚点**：`test_stability_on_spiky_profile` 断言尖峰模型下相对标准差 < 15%（旧算法在此场景分叉到 2 倍）；`test_score_never_jumps_more_than_max_step` 断言显示分单步变动 ≤ 800。若未来改算法，这两条必须继续通过。
