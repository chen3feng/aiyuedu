# 词汇量评测算法

> 实现：[`apps/api/app/services/vocab.py`](../apps/api/app/services/vocab.py)
> 测试：[`apps/api/tests/test_vocab.py`](../apps/api/tests/test_vocab.py)
> 诊断：[`apps/api/scripts/diagnose_vocab_bands.py`](../apps/api/scripts/diagnose_vocab_bands.py)

## 一句话

把 25000 个词族按词频切成 10 段，每段轮流抽词测试，用「每段认识率 × 段宽」线性累加出词汇量。这是百词斩、欧路等主流词汇量测试的「识别率 × 词频权重」做法。

## 口径

报告的「词汇量」是**识别率加权面积**，不是「认识 50% 词的拐点」：

```
词汇量 = Σ (第 i 段词频宽度 × 该段认识率)
```

其中「该段认识率」不是朴素的「该段答对数 / 该段作答数」，而是先经**单调非增平滑**、再压**猜测下限**后的「真实认识率」（见下节「四选一蒙对虚高」）。

- 对于平滑递减的知识曲线，面积 ≈ 1.11 × 50% 拐点（可预期的、恒定的比例差）。
- 与百词斩/欧路同口径，可直接横向对比。

## 词表与分段

词表：Paul Nation BNC/COCA 25000 词族（rank 1–25000），取其中可作题目的 23611 词。

```
BANDS = (0, 2000, 4000, 6000, 8000, 10000, 12000, 15000, 18000, 21000, 25000)
```

10 段，宽度依次为 2000×6 + 3000×3 + 4000×1，合计 25000。半开区间 `[BANDS[i], BANDS[i+1])`，末段含右端点 25000。

## 抽样（由易到难）

下一题始终取自**词频最低、且未抽满**的段——先把第 0 段（前 2000 常用词）抽满 `ROUNDS = 5` 词，再进第 1 段……直到末段。整卷 `MAX_QUESTIONS = 50` 题排成一条**从易到难的单坡道**，让孩子先建立信心、再逐渐探到词汇天花板（段内随机，避免每次都是同一批最常用词）。

> 出题顺序不影响最终成绩（估值只按「每段认识率」算，各段仍是 5 样本）。代价是实时分在坡道早期是「低频段下界」、随测试爬升：对低词汇孩子约第 15 题即探到天花板、之后稳定；对高词汇用户会滞后到接近尾声才追平。故高词汇用户建议答满 50 题或不要过早「提前结束」。

干扰项从目标词相邻频段（`[rank/2, rank×1.5]`）中随机抽取，保证四选一难度合理。
题面与欧路/CAT 对齐：3 个中文释义 +「以上都不对」，正确释义只出现 75% 的次数
（`CORRECT_PRESENT_RATE`），否则正确答案就是「以上都不对」；「以上都不对」固定
为最后一个选项（D）。旧版永远把正确释义放进选项，可以用排除法/词形猜出来，
三套算法的分数因此不可比。

## 估值与显示平滑

- **估值**：每次作答后，对**全部历史作答**重算 `Σ 段宽 × 认识率`。线性累加，每个词的贡献有界（≤ 段宽 / 该段已答数），天生平滑。认识率经单调平滑 + 猜测下限修正（见下）。
- **显示**：为杜绝「前 10 题爬到 10000+、错一个立刻崩」的突变，显示分朝估值逼近，但**单次变动上限 `SCORE_MAX_STEP = 800`**。
- 前 `MIN_SAMPLES = 3` 题不显示分数（返回 `null`），前端显示「测评中」。

## 参数一览

| 参数 | 值 | 含义 |
| --- | --- | --- |
| `BANDS` | 10 段（见上） | 词频分段边界 |
| `MAX_VOCAB` | 25000 | 词族上限 |
| `ROUNDS` / `MAX_QUESTIONS` | 5 / 50 | 每段抽词轮数 / 总题量 |
| `MIN_SAMPLES` | 3 | 少于该题数不显示分 |
| `SCORE_MAX_STEP` | 800 | 显示分单次最大变动 |
| `GUESS_RATE` | 0.12 | 不会时仍蒙对的概率（四选一 25% × 约一半人仍会猜）；段认识率需显著高于它才计入，并扣掉这部分（见下文与 [eudic-vocab-algorithm.md](eudic-vocab-algorithm.md) §8.3） |
| `CORRECT_PRESENT_RATE` | 0.75 | 正确释义出现在选项中的概率；否则正确答案是「以上都不对」（与欧路/CAT 题面一致） |

## 为什么不用自适应 MLE

最初实现是「自适应阶梯 + logistic 拟合」（在认识/不认识交界处密集采样，拟合 50% 拐点）。它在**平滑知识曲线**上精度高，但在真实孩子的**尖峰型知识**上有两个致命问题：

1. **同一轮内突变**：阶梯采样到的单个「生僻词碰巧认识」会大幅拉动拐点拟合，分数跳变数千。
2. **两次测评分叉**：阶梯要么「逃逸」到生僻词平台（高估），要么停在平滑拐点（低估），同一人两次结果可差一倍（实测 18.4k vs 9.8k）。

分层抽样 + 比例累加是线性估计量，**没有拐点拟合的分叉点**，因此：

| 指标 | 旧（阶梯 + MLE） | 新（分层 + 比例） |
| --- | --- | --- |
| 两轮间分叉（尖峰模型） | 2 倍 | **±10%** |
| 同一轮内单步最大变动 | 数千 | **≤ 800** |
| 校准（平滑模型） | 高估/低估都可能 | 上偏已大幅缩小（面积口径 + 猜测校正） |

> 早期试过用 isotonic 单调回归改善**稳定性**（重复测评的分叉），对诚实画像无增益（±10% vs ±10%）。但后来发现它和「猜测下限」组合能压制**四选一蒙对虚高**（见下一节），故仍予采用。

## 四选一蒙对虚高（单调平滑 + 猜测下限）

朴素比例累加有个隐含前提：**「认识」作答是真实认识，不是蒙对**。但四选一里，蒙对的题会被当成「认识」计入该段认识率。诚实用户（不会就点「不认识」）不受影响；孩子往往不愿点「不认识」而是乱猜，一次蒙对就能在 3000~4000 宽的频段上凭空抬高数百上千分。

实测（目标学生，初一男生，49 题答对 11）：

- 把 `cerecloth`（rank≈24000）、`carjack`（rank≈13000）、`populous`（rank≈9700）都「蒙对」；
- 却把 `extreme`（rank≈1350）、`examine`（rank≈1340）点成「不认识」。
- 朴素口径算出 **5200**，真实词汇量约 3000——蒙对在高频段贡献了约 2000 分虚高。

为此在 `_estimate` 里加了三道防线，把「朴素比例」修正成「真实认识率」：

1. **单调非增平滑（isotonic / PAV）**：真实认识率必须随词频排名**单调不增**（词越难，认识率越低）。低段不认识、高段反而「认识」的尖峰违反此规律、属噪声，按样本数加权合并成单调曲线，压制「生僻词蒙对」的孤峰。
2. **显著性（2026-11 改）**：每段只有 5 题，表面认识率的噪声很大。用二项比例的 **Wilson 95% 下界**判断该段是否显著高于蒙对率 `GUESS_RATE = 0.12`；下界不够高（如 2/5 = 40%，与纯猜区分不开）的段视为无知识信号、计 0。
3. **猜测校正（2026-11 改）**：保留下来的段按 `(r - 0.12) / 0.88` 扣掉蒙对贡献，再乘段宽累加。

> 2026-11 之前只有「衰减到 ≤ 25% 的段计 0」这一道点估计判断，会把高段偶然蒙对的 2/5 当成 40% 认识。真实一次 50 题的对比见
> [eudic-vocab-algorithm.md](eudic-vocab-algorithm.md) §8.3：同一批答案从 16,500 回落到 13,977
> （EAP 同批答案 12,973）。

效果（下表按 2026-11 之前的公式统计，保留作历史对照）：

| 会话 | 正确/总 | 朴素 | 修正后 |
| --- | --- | --- | --- |
| 孩子 | 11/49 | 5200 | **2800** |
| 成人 A（诚实） | 31/48 | 13875 | 13042 |
| 成人 B（诚实） | 35/48 | 9333 | 9333 |

诚实用户几乎不受影响（成人 -0~6%），因为其高段认识率本就高于 25%（真实认识稀疏但非零）；靠蒙对的低词汇用户则大幅回落。

## 实测结果

三次实跑（成年用户，非目标学生）：

| 次数 | 题量 | 最终分 |
| --- | --- | --- |
| 1 | 20（提前结束） | 14800 |
| 2 | 50 | 14800 |
| 3 | 50 | 15800 |

两次完整测评只差 7%（14800 vs 15800），且该用户答题很诚实（50 题里「猜错」仅 0–1 次，不会的都点「不认识」），无四选一猜测虚高。同时观察到清晰的「尖峰」现象：12000–15000 段认识率 40%（洼地），15000–18000 段反而 60%（生僻词反弹）——分层口径对这类知识天然稳健。

## API 端点

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/vocab/test/start` | 新建会话，返回 `session_id` + 第一题 |
| POST | `/vocab/test/answer` | 作答 `{session_id, choice, unknown}`，返回反馈 + 实时分 + 下一题；答满 50 题返回 `finished` + `result` |
| POST | `/vocab/test/finish` | 提前结束，返回最终成绩（幂等） |


**回归测试锚点**：`test_stability_on_spiky_profile` 断言尖峰模型下相对标准差 < 15%（旧算法在此场景分叉到 2 倍）；`test_score_never_jumps_more_than_max_step` 断言显示分单步变动 ≤ 800；`test_estimate_flattens_spike` / `test_estimate_zeroes_below_guess_rate` 锚定「蒙对虚高」的单调平滑 + 猜测下限修正。若未来改算法，这些必须继续通过。
